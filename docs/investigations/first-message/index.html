Investigations · 1 of 3 · Swarm Traces incident, July 2026

The first delivery between agents

The tool finds 9 write-then-read deliveries in the release. Only 4 are between named tokens, and 2 of those stay inside one estimated agent. None shows the reader using what was written. Counting agents moves the first delivery between agents by more than a day.

13 claims · 11 records cited · 563 words. Select a marked claim to see the evidence behind it.

What counts as a delivery

The release is a set of code payloads and responses. Nothing in it says that one agent sent something to another. So the tool looks for something weaker. Evidence 1: One record writes to a shared place. Later, a record from a different actor reads the same place.1 The tool calls that a delivery. Earlier versions called it a message, which says too much. It shows the reader could have seen the write. It does not show that it did, and Evidence 2: in 0 of the 9 the reader's record shares anything the writer wrote.2

Evidence 3: On the whole release the tool finds 9 deliveries.3 An earlier version found more. An audit after the deadline, then four independent reviewers, removed the ones that rested on one upload probe, a reader that listed the writer's own token and calls cut inside their verb. Most of the rest have an anonymous run on one side: a record with no token and no name. Evidence 4: Only 4 are between two named tokens, across 4 sender and receiver pairs.4

The first one

Evidence 5: The earliest of the 4 is on Jul 11 03:06.5 cred 170 posts to a Hugging Face dataset. Hours later cred 169 fetches from it. Evidence 6: At that moment 87% of the dated harmful actions were still to come.6 If this was the first time two agents talked, a warning then would have been early. The version before this one counted an upload by cred 170 and a download by cred 169 as the first; the upload turned out to be a probe of a file that already existed, so it is no longer counted.

Two tokens, one agent

But a token is not an agent. One agent can hold several tokens. Evidence 7: The tool's evidence says cred 170 and cred 169 belong to the same agent.7 Both tokens appear inside the same records. Both use the same self-chosen place names. Both run the same rare programs. The tool merges 7 tokens into one estimated agent and calls it Agent A.

Evidence 8: Counted by estimated agent, 2 of the 4 deliveries stay inside one agent.8 An agent that reads its own file is not coordination. That leaves 2 deliveries between different agents.

The first delivery moves

Evidence 9: The first delivery between two different agents is on Jul 12 07:47.9 cred 1720 commits to a dataset. A little over an hour later cred 1623, one of Agent A's tokens, reads it. Evidence 10: By then only 8% of the dated harmful actions were still to come.10 The same sign that looked early now looks late.

How sure is this

Not very, and a reader should know why. Evidence 11: Every time in this story is estimated.11 The release has no time field for these records, so the tool dates them from timestamps the agents wrote into their code. Evidence 12: The tool also grades its own deliveries by how it found the verbs. All of them are graded weak.12

Evidence 13: One reader, the authors' AI assistant, labelled all 4 named deliveries with a helper script and judged 4 of them a real write and a later read.13 That is one reader, once; no person read them by hand and nobody labelled them a second time, and the labels were changed in the same commit as the rule they score. The merge into Agent A is an estimate too. If the merge is wrong, the earlier date stands.

Source and method

Data. Forman, Kharlov, Tom et al., "Revealing the details of how OpenAI agents hacked Hugging Face", swarmtraces.org, 25 Sep 2026. Record text is not reproduced: each record links to the publisher's viewer. The release states no licence; see Datasets.

Numbers: Swarm Tracer 2.1.0, pack "code traces (Swarm Traces release)", agents counted by the "estimate" rule (tokens merged on direct evidence), on redacted_columns.csv (189,579 records). Times marked estimated are dated from timestamps in the agents' code.
