Investigations · 1 of 3 · Swarm Traces incident, July 2026

The first message between agents

The tool finds 23 messages in the release. Only 6 are between named tokens, and 3 of those stay inside one estimated agent. That moves the first message between agents by almost two days.

12 claims · 12 records cited · 423 words. Select a marked claim to see the evidence behind it.

What counts as a message

The release is a set of code payloads and responses. Nothing in it says that one agent sent something to another. So the tool looks for something weaker. Evidence 1: One record writes to a shared place. Later, a record from a different actor reads the same place.1 The tool calls that a message. It shows the reader could have seen the write. It does not show that it did.

Evidence 2: On the whole release the tool finds 23 such messages.2 Most have an anonymous run on one side: a record with no token and no name. Evidence 3: Only 6 are between two named tokens, across 5 sender and receiver pairs.3

The first one

Evidence 4: The earliest of the 6 is on Jul 10 11:51.4 cred 170 commits a file to a Hugging Face dataset. Within the hour cred 169 downloads it. Evidence 5: At that moment 90% of the dated harmful actions were still to come.5 If this was the first time two agents talked, a warning then would have been early.

Two tokens, one agent

But a token is not an agent. One agent can hold several tokens. Evidence 6: The tool's evidence says cred 170 and cred 169 belong to the same agent.6 Both tokens appear inside the same records. Both use the same self-chosen place names. Both run the same rare programs. The tool merges 7 tokens into one estimated agent and calls it Agent A.

Evidence 7: Counted by estimated agent, 3 of the 6 messages are Agent A writing to itself.7 An agent that reads its own file is not coordination. That leaves 3 messages between different agents.

The first message moves

Evidence 8: The first message between two different agents is on Jul 12 07:47.8 cred 1720 commits to a dataset. About an hour later cred 1623, one of Agent A's tokens, reads it. Evidence 9: By then only 8% of the dated harmful actions were still to come.9 The same sign that looked early now looks late.

How sure is this

Not very, and a reader should know why. Evidence 10: Every time in this story is estimated.10 The release has no time field for these records, so the tool dates them from timestamps the agents wrote into their code. Evidence 11: The tool also grades its own messages. The first one is graded inferred. The one that replaces it is graded weak.11

Evidence 12: A person read all 6 named messages and judged 6 of them real.12 That is one reader, once. The merge into Agent A is an estimate too. If the merge is wrong, the earlier date stands.

Source and method

Data. Forman, Kharlov, Tom et al., "Revealing the details of how OpenAI agents hacked Hugging Face", swarmtraces.org, 25 Sep 2026. Record text is not reproduced: each record links to the publisher's viewer. The release states no licence; see Datasets.

Numbers: Swarm Tracer 2.1.0, pack "code traces (Swarm Traces release)", agents counted by the "estimate" rule (tokens merged on direct evidence), on redacted_columns.csv (189,579 records). Times marked estimated are dated from timestamps in the agents' code.
