How these are made

Each story is a small JSON file with no numbers in it. A build script fills every number and record from the dataset, and writes an evidence bundle that holds only the cited records. A check fails the site if a claim has no record, if a number on a page differs from the bundle, or if anything that looks like a secret is published.

The pages publish record ids, times, tokens and what the tool judged. They do not reproduce record text: each record links to the publisher's own viewer.

Data. Forman, Kharlov, Tom et al., "Revealing the details of how OpenAI agents hacked Hugging Face", swarmtraces.org, 25 Sep 2026. The release states no licence; see Datasets for what we publish and why.

Numbers: Swarm Tracer 2.1.0, pack "code traces (Swarm Traces release)", agents counted by the "estimate" rule (tokens merged on direct evidence), on redacted_columns.csv (189,579 records). Times marked estimated are dated from timestamps in the agents' code.
