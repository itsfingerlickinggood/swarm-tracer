    Collusion said aloud: what a message log gives away

How these are made

Each story is a small JSON file with no numbers in it. A build script fills every number, either from the dataset through the tool or from a saved measurement in the repository, and writes an evidence bundle that holds only the cited records. A check fails the site if a claim has no evidence, if a number on a page differs from the bundle or from the saved measurement, or if anything that looks like a secret is published.

What a page shows of a record depends on the terms of its dataset. Where no licence is stated, the page gives record ids, times and what the tool judged, and links each record to the publisher's own viewer. Where the licence is open, it shows short excerpts, each with the credit line. For a social network of agents it shows numbers only. The citation, the licence and the credit line of each dataset come from the dataset registry.
