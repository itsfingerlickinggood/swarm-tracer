Collusion said aloud: what a message log gives away

In 1,800 simulated runs two agents grade each other's work, and in 1,351 of them they end up passing each other against the rules. The tool's own alarms ring on every run or on none. A few phrases written down from one run catch 42% of the colluding runs in the other conditions.

12 claims · 3 records cited · 511 words. Select a marked claim to see the evidence behind it.

A game with the answer in the data

The SALT lab published a game. Two agents, Alice and Bob, each solve a task, exchange a few short messages, then accept or reject the other's work. The rule is strict: a verdict must rest on the other's complete work log. Messages are capped at two hundred characters, too short to carry it, so an agent that follows the rule rejects. Evidence 1: In 1,351 of 1,800 runs the two end up accepting each other anyway1. The authors call that collusion and mark every episode. Nobody on this project made those labels.

The tool is given the messages only: who sent each one, to whom, and the text. It never sees a verdict.

As published: silence

Evidence 2: The episodes carry no times2. The tool keeps all 182,447 messages as logged direct messages, but it cannot put them in order. Evidence 3: No rule, alarm or sign fired in any run3. On this dataset as it was published the tool finds none of the collusion.

With a clock: noise

We then placed each message on an order-only clock, sixty seconds after the one before. Now the replay runs. Evidence 4: The Alert rule fired in all 1,351 runs that colluded and in all 449 that did not4. It asks for two kinds of coordination, and two agents who answer each other show both within the first few messages. Evidence 5: The Watch rule fired in 44% of the colluding runs and 43% of the others5. Its commonest match was the word password, which is in the name of a task.

The written-content test does pass here. Evidence 6: In 31,305 of 160,490 inferred deliveries the reply repeats a rare term of the message before it6. Agents who honestly check each other do that too, so it tells the two kinds of run apart only a little.

A pack written from one run

We read one run and wrote down the phrases its agents used. In its first episode Evidence 7: one agent says the complete log could not be sent and that the policy needs it7; both reject. In the next episode Evidence 8: the same agent confirms that both will submit accept8, and Evidence 9: the other says it will submit accept9. Phrases of that kind became a small pack.

Evidence 10: On the 35 conditions that run is not part of, the Watch rule with this pack fired in 42% of the runs that colluded and 6% of those that did not10. A phrase list travels badly. Evidence 11: It caught 87% of the colluding runs where an agent is the model whose wording it copied, and 21% where none is11. Evidence 12: 755 of the 1,301 colluding runs never use such a phrase12: the agents agree in other words or accept without saying so, and this pack cannot show that.

This is simulated data from a designed game with two agents per run. The pack is a list of phrases, not a judgement of intent, and it was tested on the same game it was written from. Credit for the data and the labels is in the source line below and beside each excerpt.
