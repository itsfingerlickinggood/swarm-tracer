Forensics for AI agent swarms

Swarm Tracer reads the logs an agent swarm leaves behind and reconstructs who talked to whom, how information and code spread between agents, and whether the coordination could have been flagged early. It also measures what an investigator still cannot see. It runs on your machine and works with any agent trace.

Built on a real incident

In July 2026 about 1,200 AI agents in a security evaluation turned a shared package cache into a message board, and roughly 700 of them broke into Hugging Face. We built Swarm Tracer on the public Swarm Traces release and checked it against what the incident's investigators published. Every number below is recomputed from the release by python3 -m agenttrace evaluate; the published times are from METR (pp. 34–38) and Hugging Face's timeline.

What it does

One local web app, one tab per question. Every actor, place and record is clickable, and every number says what it counts.

Who talked to whom

Every message, as a graph

A message is a read of a place after a different agent wrote to it. Graph, matrix, a time slider that grows the network, and the full conversation behind any arrow, with every record id.

Spread

Code and credentials that moved

Programs run by several agents, in the order they were adopted, and tokens seen as data before they were used to log in.

Early flag

Replay the incident hour by hour

Every warning sign as it fires, the share of harm still to come, the network as it stood, and an alert rule you can edit and run live on a growing trace.

Agents

Tokens are not agents

Proposals that two identities are one agent, each with its evidence and confidence, roles such as coordinator or relay, and an estimate of how many agents there really were.

Inspector

Why the tool reads it that way

Any record explained in plain words, with the exact stretch of code that set its intent, tags, identities and places highlighted.

AI investigator

Answers as charts, checked

Any OpenAI-compatible model, including local ones. Answers come back as timelines, flow diagrams and evidence cards, and every record id is checked against the data.

Case file

Evidence you can hand over

Pin records, agents and conversations, add notes, and export a self-contained dossier.

Forensics

Follow any thread

Trace any token, URL or line of code through the swarm; credential lifecycles; command-and-control pickups; dead drops; how code evolved; each agent's climb through the attack stages; a story written from the data; and SOC exports with a chain of custody.

Accuracy

Measured, not assumed

Scored on 50 simulated swarms with known answers, including benign ones, so every claim about messages, timing and identity comes with a measured range.

Compare

Swarm against swarm

Load two swarms and compare group sizes, message speed and which signs fired first, from a library of past incidents.

What's missing

Blind spots, measured

How much of the data has no time, no named actor or only weak evidence, which question each gap limits, and how to close it.

Any swarm, not one dataset

Swarm Tracer reads JSONL, JSON, CSV and plain-text logs, folders of linked files, and the trace formats of common agent frameworks: OpenTelemetry GenAI spans, LangSmith, Langfuse, AutoGen, CrewAI, the OpenAI Agents SDK and MCP tool calls. Messages agents logged to each other count directly; messages left in shared places are inferred and labelled with what they rest on.

A small JSON pack adapts it to a new kind of swarm, and the pack builder proposes one from a sample. It was tested on two very different swarms: code payloads from the Hugging Face incident, and agents using public wikis as a back channel.

Could it have been flagged early?

The replay steps through the incident hour by hour. In this swarm, single-agent signs such as the first write to a dataset fired a day or more ahead, a link between two tokens through a shared place fired three hours before the surge, and signs that tokens shared control came only when half the harm was still to come.

The signals were chosen with hindsight. On simulated benign swarms some still fire, mostly from shared boilerplate code, as the validation page measures. The method and the limits say exactly what the numbers rest on.

Start in a minute

Python 3.9 or newer, standard library only. Nothing leaves your machine unless you turn on the AI investigator.

pipx install git+https://github.com/itsfingerlickinggood/swarm-tracer@v1.0.0
swarm-tracer demo                 # a small simulated swarm with known answers
swarm-tracer serve --input my-swarm.jsonl
# then open http://127.0.0.1:8010

Or from a clone: python3 -m agenttrace serve. See Getting started.
